# iPhone 快捷指令：把 iCloud 里的血压记录导入「健康」

> 配合 Mac 端守护进程使用。守护进程把每次测量写成 JSON 文件放到
> `iCloud Drive / bp-health / inbox/`；本快捷指令负责把文件读进 iPhone「健康」App。

每个 JSON 文件的样子：

```json
{
  "time": "2026-10-10T16:34:28",
  "systolic": 115,
  "diastolic": 91,
  "heart_rate": 69,
  "flags": 0
}
```

---

## 搭建步骤（共 7 步）

### 1️⃣ 获取文件夹内容
- 搜索「文件夹」→ 添加「**获取文件夹内容**」
- 点动作里的「文件夹」→ 选取 `iCloud Drive → bp-health → inbox`
- 如果出现「显示文稿选取器」开关 → **关闭**
- （找不到文件夹时：先在「文件」App 里建好 `iCloud Drive/bp-health/inbox`）

### 2️⃣ 重复每一项 ⭐（最容易错的一步）
- 搜索「重复」→ 选择「**重复每一项**」（部分版本显示为「**为每个项目重复**」）
  - ❌ **不要**选「重复 N 次」——那是纯计数、不会逐个文件处理
- 把它接在上一步后面：重复对象选「**文件夹内容**」
- 添加后会出现「重复每一项」和「结束重复」两个标记
- ⚠️ **接下来的所有动作（3~7 步）都必须放在这两个标记之间**（拖进去、缩进在循环内部）

### 3️⃣ 读文件 → 词典
- 搜索「从输入」或「词典/字典」→ 添加「**从输入中获取词典**」（新版叫「从输入中获取字典」）
- 输入：选「**重复项目**」（循环里当前的那个文件）
- 💡 如果运行后这一步结果是空的：在它前面加一个「**获取文件**」（文件=重复项目），再把本动作的输入改选「文件」

### 4️⃣ 取出 4 个值
- 搜索「词典/字典」→「**获取词典值**」（新版「获取字典值」），**添加 4 次**：

| 第几个 | 键（Key） | 含义 |
|--------|-----------|------|
| ① | `systolic` | 收缩压 |
| ② | `diastolic` | 舒张压 |
| ③ | `heart_rate` | 心率（⚠️ 中间是**下划线**，不是空格）|
| ④ | `time` | 测量时间 |

- ⚠️ 4 个动作的「词典」参数**都选第 3 步的那个「词典」输出**（同一个），不要选成上一个取值动作的结果！

### 5️⃣ 写入健康：血压
- 搜索「健康」→「**记录健康样本**」
- 类型：**血压**（选中后自动出现两个值框）
- 收缩压：选第 4 步里 ①`systolic` 的词典值
- 舒张压：选 ②`diastolic` 的词典值
- 日期（点「显示更多」）：选 ④`time` 的词典值（这样记录时间是实际测量时间）

### 6️⃣ 写入健康：心率
- 再添加一个「**记录健康样本**」
- 类型：**心率** → 值：选 ③`heart_rate` 的词典值 → 日期同上选 ④`time`

### 7️⃣ 删除已导入文件（防重复）
- 搜索「文件」→「**删除文件**」→ 文件选「**重复项目**」

---

## 运行 & 授权
1. 点 ▶️ 运行 → 首次会请求「健康」写入权限 → **允许**（血压、心率）
2. 成功后：inbox 里的文件被逐个删除，「健康」App 出现对应记录
3. 如果健康里没有记录：设置 → 健康 → 数据访问与设备 → 快捷指令 → 打开「血压」「心率」的写入开关

## 调试技巧
- 运行后在编辑界面看**每个动作下方的灰色结果文字**：哪个是空的/不对，问题就在那里
- 想看读到的内容：在第 3 步后面加一个「**快速查看**」，运行时弹出词典内容
- **调试期**：先把第 7 步「删除文件」拖出循环（或删掉），避免文件被删后不好反复试

## 自动化（可选）
自动化标签 → 新建「当连接到家里 Wi-Fi 时」→ 运行本快捷指令 → 关闭「运行前询问」。
